Mini aula vertical de GitHub, uns 50 segundos. A dor é a pasta do trabalho em grupo. A solução cabe em três palavras: Salvou, Enviou, Juntou.

A narração está em `public/narracao.mp3` e cada cena entra na palavra certa. A voz é sintética, não um clone.

## Stack

- React 19 e TypeScript
- TanStack Start, Vite e Tailwind CSS 4
- Narração em MP3, efeitos curtos no navegador

## Estrutura

```
src/components/player.tsx
src/components/stage.tsx
src/components/characters.tsx
src/lib/narration.ts
public/narracao.mp3
public/og.jpg
public/favicon.svg
```

## Como rodar

```bash
git clone https://github.com/gabrielteramae/git-em-45s.git
cd git-em-45s
npm install
npm run dev
```

Abre no navegador. Toca **Assistir**. No computador, **Apresentar** esconde a cola e deixa só o vídeo.
