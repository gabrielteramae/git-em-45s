# Contribuir

A peça é uma aula de uns 50 segundos. Uma ideia por cena.

1. Branch a partir de `main`.
2. Não mudar o tempo de uma deixa sem ouvir `public/narracao.mp3`.
3. `npm test` antes do pull request.
4. Pedir review. Não juntar o próprio PR sem outra pessoa ter lido, se a entrega pedir review.
